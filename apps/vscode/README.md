# Hooshyar

Hooshyar is an AI coding agent for Visual Studio Code. It can inspect a workspace, propose and apply changes, run commands, and use configured MCP tools after your approval.

## Getting started

1. Open the Hooshyar view from the Activity Bar.
2. Enter your Hooshyar API key in the onboarding screen.
3. Select a model and start a task.

## Privacy

Your API key is stored in VS Code Secret Storage. Requests are sent to the configured Hooshyar API provider.
